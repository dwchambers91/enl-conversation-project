# Facial Expression & Conversational Success — Reproducible Analysis Demo

A small, end-to-end R/Quarto pipeline that mirrors the kind of data-processing and
analysis work done in the **Emotion and Neurodiversity Laboratory (ENL)** at the
Center for Autism Research, CHOP. Built as a portfolio piece for a Clinical Research
Assistant application.

It takes raw, behavioral data, cleans and scores it, runs the analysis,
produces a poster-quality figure, all reproducible from a single `analysis.qmd`.

> **Data are 100% synthetic and generated by `R/00_generate_data.R`. No human
> subjects, no PHI, no real clinical data.** The pipeline is written to mirror an
> IRB-approved, de-identified workflow (subject IDs only, no identifying fields).

## The research question (mirroring the ENL grant)

> Do facial expressions and other non-verbal behaviors predict conversational
> success and satisfaction, and does that relationship differ between autistic and
> non-autistic adolescents?

**Synthetic variables**
- `group` — autistic / non-autistic
- Facial action units (OpenFace-style intensities, 0–5):
  `au06_cheek_raiser`, `au12_lip_corner_puller` (smiling), `au04_brow_lowerer`
- `smile_reciprocity` — how often the participant's smiles were mirrored by the partner
- An 8-item **Conversation Satisfaction Questionnaire (CSQ)**, Likert 1–5, with two
  reverse-scored items and some missing responses (to make cleaning realistic)
- `conversational_success` — the continuous outcome

## How to run

Requires **R (≥ 4.1)** and **Quarto**. Install packages once:

```r
install.packages(c("tidyverse", "effsize", "gt", "broom", "quarto"))
```

Then, from the project folder:

```bash
Rscript R/00_generate_data.R
quarto render analysis.qmd
```

`analysis.qmd` also generates the data automatically if `data/` is empty, so
`quarto render analysis.qmd` alone works too.

## Notes for reviewers / interviewers

The generative model in `00_generate_data.R` intentionally builds in a *real* signal
(smiling and smile reciprocity predict conversational success, with a group
interaction) so the analysis has something to recover. In real ENL data these
relationships would be the empirical question — here they're a controlled ground
truth to demonstrate that the pipeline detects what's actually there.
